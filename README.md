# مسكن للتسويق العقاري

برنامج عقارات عربي: إعلانات وبحث وخريطة للعملاء، ولوحة سمسار فيها العملاء والمتابعات والعمولات والملاك والعقود والتقارير.

- الموقع: GitHub Pages
- السيرفر وقاعدة البيانات: Supabase (جداول `maskan_*`)
- دخول السمسار: من القايمة ← "دخول السمسار" (أول حساب يتعمل هو حساب السمسار)
